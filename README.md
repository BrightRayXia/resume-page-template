# resume-page

单文件 HTML 个人介绍页 —— 一份 HTML，同时是「完整个人介绍」和「可下载的 PDF 简历」。

> 📌 本仓库为**示例模板**：页面内容为虚构的示例人物（明霞）与虚构项目，替换成你自己的信息即可使用。

## 在线演示

**GitHub Pages：** https://brightrayxia.github.io/resume-page-template/

## 特性

- **四套主题切换**：右上角悬浮卡的调色盘一键切换——经典蓝 / 电光紫 / 浅色霓虹 / 深色青霓虹，主题记忆在本地，刷新不丢失
  - 经典蓝：克制文档风
  - 电光紫：玻璃拟态毛玻璃卡片 + 噪点纹理 + Emoji 点缀
  - 浅色霓虹：光晕弥散 + 毛玻璃（默认）
  - 深色青霓虹：深色底 + 青色光晕，打开时全屏「hello」开场动画，几秒后翻页进入内容
- **双形态一体**：一个 `index.html` 同时包含完整版个人介绍 + 简洁版简历（原文文档）
- **一键导出 PDF**：点按钮调用浏览器打印，自动输出 A4 排版的简洁版简历（始终白底、不受主题影响）
- **胶囊导航**：左侧大纲，当前章节为渐变胶囊高亮，悬浮其他项展开显示名字
- **宽屏 / 居中切换**：右上角悬浮卡片一键切换内容宽度
- **三栏布局**：导航、内容、操作卡片互不遮挡，宽屏时两侧保留空隙
- **内联 SVG 图标**：联系方式、操作按钮、章节标题均为手写线性图标，零依赖
- **零依赖**：纯 HTML + CSS + 少量原生 JS，双击即可打开，可离线使用
- **响应式**：手机端自动切换为简洁顶栏

## 使用

1. 打开 `index.html` 即可浏览
2. 右上角「🎨 主题」切换 4 套视觉风格
3. 点右上角「下载 PDF」导出简历
4. 点「⤢ 宽屏」切换内容宽度
5. 点「简洁版」切换为简历视图

## 定制

- 所有内容都在 `index.html` 的 `<main>` 内，直接修改即可
- 简洁版简历在 `<div class="simple-view">` 内，替换为自己的简历原文即可
- 主题在 `<style>` 开头的 `:root` 与 `body[data-theme="..."]` 变量块里，改几个颜色值即可定制自己的主题；想加第 5 套主题，复制一个 `data-theme` 块 + 在 dock 里加一个色点即可

## 技术

- 无框架、无构建、无 CDN，单文件即可分享
- 打印版式通过 `@media print` 实现
- 布局基于 CSS Grid 三栏，导航为固定定位 + 动画
